# easyquotation 统一术语表

本文是 `bse` 分支文档的术语与单位依据。Python API、来源字段及证券代码保留现有
英文标识；不同数据源返回结构不完全相同，调用方不能仅凭相同字段名推断同一含义。

## 行情来源与代码

| 标准英文／标识 | 标准中文 | 含义与本地映射 | 单位 |
| --- | --- | --- | --- |
| `sina` | 新浪行情 | `easyquotation.use("sina")` 返回 `Sina` 适配器 | 来源快照 |
| `tencent` / `qq` | 腾讯行情 | 两个名称都返回 `Tencent` 适配器 | 来源快照 |
| `jsl` | 集思录 | 分级基金与 ETF 数据适配器 | 来源记录 |
| `timekline` | 分时 K 线 | 腾讯分时数据适配器 | 价格与成交数量字符串 |
| `daykline` | 港股日 K 线 | 腾讯港股日线数据适配器 | 来源字符串值 |
| `hkquote` | 港股行情 | 腾讯港股即时报价适配器 | 见返回字段 |
| `sh` / `sz` / `bj` | 沪市／深市／北交所前缀 | `prefix=True` 时行情字典 key 的两字母市场前缀 | 证券代码前缀 |

北交所自动识别前缀为 `43`、`83`、`87`、`92`；显式 `bj` 前缀保持不变。该规则只
决定请求代码前缀，不把历史证券代码映射为其他身份。

## 新浪与腾讯行情字段

| 字段 | 新浪适配器 | 腾讯适配器 | 标准中文／单位 |
| --- | --- | --- | --- |
| `open` / `high` / `low` / `close` / `now` | 数值 | 数值 | 开盘／最高／最低／昨收／现价；人民币股票通常为元／股，指数为点，基金及其他证券按来源与品种解释 |
| `turnover` | 解析为整数 | 来源换手率字段，可为空 | 新浪为成交数量（股票通常为股、基金通常为份）；腾讯为换手率，不能混用 |
| `volume` | 解析为浮点数 | 来源成交量乘 100 | 新浪为成交金额（人民币计价证券通常为人民币元）；腾讯为成交数量（股票通常为股、基金通常为份）；其他品种按来源契约解释 |
| `bidN_volume` / `askN_volume` | 来源整数 | 来源“手”乘 100 | 对按股交易的证券表示买／卖 N 档委托股数；其他品种按来源契约解释 |
| `date` / `time` | 分开的日期与时间字符串 | 不提供这两个字段 | 新浪观测日期／时间 |
| `datetime` | 不提供 | `datetime` 对象 | 腾讯观测时间 |
| `成交额(万)` | 不提供 | 来源值乘 10,000 | 腾讯成交额；人民币计价证券通常为人民币元，其他品种的币种与单位按来源契约确认 |

`market_snapshot()`、`real()` 和 `stocks()` 返回来源适配器字典，不是跨来源统一模式。
需要稳定消费契约时，应固定来源并对实际字段进行校验。
